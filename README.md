# Partner discount calculator

Функция `calculate_partner_discount(total_quantity)` возвращает персональную скидку партнёра в процентах по суммарному объёму купленной продукции.

| Объём продукции | Скидка |
| --- | --- |
| Меньше 10 000 | 0% |
| От 10 000 до 49 999 | 5% |
| От 50 000 до 299 999 | 10% |
| 300 000 и больше | 15% |

## Запуск тестов

```bash
python -m unittest -v
```

## Получение скидки из базы данных

Для работы требуется PostgreSQL с таблицами `partners`, `deliveries` и `delivery_items`.
Настройте подключение через переменные окружения из `.env.example` и выполните:

```bash
pip install -r requirements.txt
python app.py 1
```

Программа выведет словарь с идентификатором партнёра, названием, суммарным объёмом товаров и текущей скидкой.

## Графический интерфейс

```bash
python partner_list_ui.py
```

Интерфейс показывает карточки партнёров, текущие скидки и данные, загруженные из базы PostgreSQL.
Логотип и иконка окна находятся в папке `resources`.

## Финальная проверка

```bash
python -m unittest -v
python app.py 1
python partner_list_ui.py
```

Тесты включают проверку партнёра без отгрузок: приложение получает объём `0` и отображает скидку `0%`.
