# Partner discount calculator

Функция `calculate_partner_discount(total_quantity)` возвращает персональную скидку партнёра в процентах по суммарному объёму купленной продукции.

| Объём продукции | Скидка |
| --- | --- |
| Меньше 10 000 | 0% |
| От 10 000 до 49 999 | 5% |
| От 50 000 до 299 999 | 10% |
| 300 000 и больше | 15% |

## Запуск тестов

```bash
python -m unittest -v
```
